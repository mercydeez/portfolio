## 🚀 Getting Started with This Portfolio

This portfolio is built using React and can be easily customized.

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/mercydeez/developerFolio.git

# Navigate to the project directory
cd developerFolio

# Install dependencies
npm install

# Start the development server
npm start
```

### Build for Production

```bash
# Create production build
npm run build

# Deploy to GitHub Pages
npm run deploy
```

### Customization

Edit `src/portfolio.js` to customize:
- Personal information
- Projects
- Skills
- Experience
- Achievements
- Contact details
